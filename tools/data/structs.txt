# Struct layouts for Ghidra (tools/ghidra/ApplyStructs.java, category /bro) and
# the field-usage reports (tools/namepack.py fields). Only verified fields; the
# rest stays undefined so Ghidra shows field_0x<offset> and the export records it.
#
#   struct NAME SIZE                 starts a struct (size in hex)
#     OFFSET NAME TYPE  # evidence   a field; TYPE: int, uint, short, ushort, char,
#                                    uchar, float, pointer, another struct, NAME*,
#                                    TYPE[N]
#   global ADDRESS|NAME TYPE         types a global
#   globals CSV TYPE                 types every row of a CSV (address column)
#   param FUNCTION INDEX TYPE        types a stack parameter (0 = first)
#   param FUNCTION REGISTER TYPE     types a register argument (custom storage; fnpack
#                                    shows the register inputs)
#   return FUNCTION TYPE             types a return value
#
# Names are neutral (Q3/RTCW names are fine, no later-title identifiers).
